# «Цитадель» 1.1.2 — «Живой гарнизон»

Сборка: `dist/Citadel-1.1.2.apk`. Механики 1.0.1 (COM, доверие, помощники, делегирование, приказы, карта траншей, тыл, смены, угроза штабу, победа/поражение) сохранены; кампания проверена прогонами ботом.

## Что сделано
**Наполнение территории** (`world/props.js`, всё слито в общие меши):
- штабной двор — генератор под навесом со звуком, бочки, тележка, фонари на столбах (горят ночью), укрытия из мешков;
- медпункт — флаг с красным крестом, носилки, вёдра, верёвка с бинтами;
- склад — бочки, весы, раскрытые ящики, гильзы; количество ящиков и мешков = реальный запас;
- инженерный двор — штабели досок, лопаты, катушка проволоки;
- места отдыха — полевая кухня с огнём, столы и скамьи;
- линии связи на кольях вдоль ходов сообщения;
- передовая — ниши с ящиками, лопаты, перископы, гильзы, воронки, обломки обшивки, разбитые участки.

**Люди** (`world/people.js`): шея, нос, уши, затылок, сапоги, 5 типов лиц (усы, щетина, борода, шрам), 4 оттенка кожи, разброс оттенков формы.
Роли видны по внешности:

| Роль | Отличие |
|---|---|
| Боец | каска, скатка, подсумки, фляга |
| Командир | фуражка с околышем, портупея, планшет, погоны, тёмные галифе |
| Штабной | фуражка, портупея, более светлая форма |
| Медик | пилотка, светлый халат, повязка с красным крестом, сумка |
| Связист | пилотка, аппарат за спиной, катушка |
| Сапёр | каска, лопата за спиной |
| Снабженец | ушанка, стёганая ватная куртка |
| Противник | серая форма, ранец |

**Анимации:** целевые позы с плавным переходом (без рывков), ходьба и бег, дыхание; случайные действия по позе (оглядеться, поправить каску, переступить, пригнуться, выглянуть, потянуться, поговорить, писать, листать бумаги). Новые позы: стрельба с колена, лёжа, у телефона, с бумагами, за столом, работа инструментом, перенос ящика.

**Видимый бой** (`world/battle.js`) — всё выведено из симуляции:
- подготовка атаки: вдали перебегают фигуры (шумно — на показной атаке, почти никого — перед скрытым ударом);
- атака: число фигур = численность `op.str`, рубеж = `op.pressure`, перебежки, залегание, стрельба;
- убитые падают и лежат, при отходе уцелевшие убегают, при прорыве противник в траншее;
- трассеры в обе стороны, вспышки, фонтанчики земли, очереди пулемётных гнёзд;
- наши потери видны: боец падает на позиции;
- штурм КП из захваченного сектора идёт к штабу.

Скат за передним краем сделан пологим, бруствер — с бойницами: из траншеи видно поле.

**Личный состав** (клавиша P, кнопка «ЛЮДИ», доска в штабе):
- таблица взводов: командир и его характер, где находится, состояние по последнему докладу или осмотру (с временем), что требует внимания; проблемные взводы — вверху, с флажком;
- карточка взвода в формате «Командир / Подразделение / Текущая задача / Состояние»;
- в карточке: запросы, смена задачи (лично, по телефону или связным — в зависимости от связи), «оставить на усмотрение командира», полномочия взвода (отход, инициатива — важнее общих поручений), вызов в штаб, доклады взвода, смена или назначение командира из кандидатов, кадровый журнал.

**Штаб:** стол начальника штаба с лампой под зелёным абажуром, стол писаря с машинкой, полки с папками, доска личного состава, табуреты, вешалка с шинелью и каской, чайник на печке, дрова, половик, фото, зеркало, кабели, морзянка, вторая рация, график дежурств.
Люди работают: Орлов за столом, иногда идёт к карте; писарь печатает; Мирон и радист берут трубки при вызовах.

**Звук:** ветер снаружи, тон помещения, неразборчивые голоса (в штабе и рядом с людьми), пишущая машинка, морзянка, гул генератора по расстоянию; шаги по доскам, земле и грязи; пулемётные очереди, свист снаряда перед близким разрывом, выстрелы — громкость по расстоянию.

**Оптимизация:**
- статика слита в общие меши;
- человек — 6 мешей, общая геометрия и текстура по типу;
- дальние люди не рисуются и не анимируются;
- противник берётся из пула (до 40 фигур);
- все трассеры — одним вызовом отрисовки;
- ограничено число звуков выстрелов в секунду;
- отрисовок за кадр обычно 20–200.

## Честно о том, что не сделано или упрощено
- Головы людей поворачиваются только при случайном «оглядеться»; за игроком специально не следят (повернуться может только корпус целиком).
- Бой показан на уровне отделений: до 16 фигур на атаку. Отдельные попадания не связаны с конкретными потерями симуляции — потери считает симуляция, картинка их отображает.
- Ночью без осветительных ракет наступающих почти не видно — это задумано, но может показаться пустым.
- Разговоры NPC звучат как неразборчивый гул: озвучки речи нет.
- На реальном телефоне производительность не проверялась (только в браузере и эмуляции).
