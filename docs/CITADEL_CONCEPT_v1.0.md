# «ЦИТАДЕЛЬ» — Концепт-документ версии 1.0

**Жанр:** симулятор командования осаждённым гарнизоном от первого лица
**Визуал:** 3D в стилистике PlayStation 1 (low-poly, пиксельные текстуры, туман, дрожание вершин)
**Платформы (цель):** PC, Android
**Статус документа:** концепция, без кода

## 1. Основная идея игры

Игрок — **капитан, командир окружённого гарнизона** на высоте/в укрепрайоне под условным названием «Цитадель». С ним — четыре стрелковых взвода, инженерный взвод, миномётная секция, медпункт и маленький штаб.

Задача: **продержаться N суток** до деблокирующего удара или выполнить прорыв по сигналу сверху.

Игра — не о стрельбе и не о микроконтроле. Это игра о:
- **доверии к людям**, которые видят бой лучше тебя;
- **решениях при неполной информации**;
- **управлении убывающими ресурсами** — патронами, людьми, силами, временем;
- **ответственности** за последствия собственных приказов.

Ключевое ощущение: *«Я сижу в сыром блиндаже под лампой. Звонит телефон. Я не вижу, что происходит на севере. Я должен решить, верю ли я лейтенанту Ковалю».*

Главный «экран» игры — **штабной блиндаж**, физическое 3D-пространство, где каждый объект — интерфейс.

## 2. Главная игровая петля

```
 ┌─► ПОЛУЧИТЬ ИНФОРМАЦИЮ (телефон, рация, курьер, доклад, наблюдатель)
 │        │
 │   ОЦЕНИТЬ (карта, журналы, сопоставить доклады, проверить время доклада)
 │        │
 │   РЕШИТЬ (что, кому, с каким риском, чем пожертвовать)
 │        │
 │   ПЕРЕДАТЬ ПРИКАЗ (лично / телефон / рация / курьер — с задержкой и риском искажения)
 │        │
 │   КОМАНДИР ИНТЕРПРЕТИРУЕТ (характер, доверие, усталость, обстановка)
 │        │
 │   ПОДРАЗДЕЛЕНИЕ ДЕЙСТВУЕТ (симуляция боя вне поля зрения игрока)
 │        │
 │   СИТУАЦИЯ МЕНЯЕТСЯ (противник реагирует, ресурсы тратятся)
 └────────┘
```

**Три уровня петли:**

| Уровень | Длительность | Содержание |
|---|---|---|
| Микро | 30 сек – 3 мин | Звонок, доклад, короткий приказ |
| Мезо | 1–3 игровых часа | Отражение атаки, смена взвода, распределение поставки |
| Макро | Сутки | Планирование ночи, ротация, учёт потерь, подготовка к следующему дню, «вечерний совет» |

Время идёт непрерывно (≈1 игровой час = 4–6 реальных минут), с возможностью ускорения в спокойные периоды и **автоматическим замедлением** при входящем экстренном докладе. Паузы нет (опционально — «тактическая пауза» в режиме лёгкой сложности).

## 3. Роль игрока

Игрок — **капитан**, а не солдат и не «бог».

**Что игрок делает:**
- принимает доклады и задаёт уточняющие вопросы;
- ведёт карту (сам ставит пометки карандашом — карта не обновляется автоматически!);
- отдаёт приказы командирам взводов, инженерам, медпункту, тыловику;
- распределяет резерв, снабжение, инженеров, мины, медикаменты;
- поощряет, наказывает, снимает с должности, назначает;
- связывается с вышестоящим командованием (запросы, отчёты, получение сроков деблокады);
- принимает моральные решения (раненые vs боеприпасы, отход vs удержание).

**Что игрок НЕ делает:**
- не управляет отдельными бойцами;
- не видит бой напрямую (кроме выхода к амбразуре штаба / траншее рядом со штабом — см. п. 8);
- не знает точной численности противника.

**Перемещение:** вид от первого лица внутри штаба. Выход наружу возможен (траншея, НП рядом со штабом, медпункт, склад), но это **риск** — обстрел, а пока капитан вне штаба, звонки остаются без ответа. Посещение блиндажа взвода — сильный жест (+доверие, +мораль), но это 20–40 минут игрового времени вне связи.

## 4. Система COM (Command Officer)

COM — ядро игры. Каждый командир — автономный ИИ-агент с личностью, памятью и собственным пониманием ситуации.

### 4.1. Архитектура командира

```
ВОСПРИЯТИЕ ─► МОДЕЛЬ ОБСТАНОВКИ ─► ИНТЕРПРЕТАЦИЯ ПРИКАЗА ─► ПЛАН ─► ИСПОЛНЕНИЕ ─► ДОКЛАД
     ▲              (своя, неполная)        (личность + доверие)     (Utility AI / HTN)        │
     └────────────────────────── ПАМЯТЬ (эпизоды, отношения к капитану) ◄──────────────────────┘
```

1. **Восприятие** — что видят бойцы и наблюдатели взвода; качество зависит от погоды, ночи, усталости.
2. **Модель обстановки** — собственная (ошибочная!) оценка: «на нас идёт рота» — когда на самом деле взвод.
3. **Интерпретация приказа** — приказ превращается в *намерение* (Intent) с допусками.
4. **Планирование** — HTN-планировщик выбирает тактическую схему (оборона по фронту, в глубину, огневой мешок, контратака...), Utility AI — конкретные решения внутри неё.
5. **Исполнение** — распределение отделений, пулемётов, резерва взвода.
6. **Доклад** — что и как командир сообщает игроку (может приукрасить, преуменьшить, промолчать).

### 4.2. Характеристики

Все значения 0–100, скрыты от игрока. Игрок узнаёт их **только через поведение**, личное дело (грубые формулировки) и записи в журнале.

| Параметр | Что делает в поведении |
|---|---|
| **Опыт** | Качество тактических планов, точность оценки противника, умение строить огневую систему |
| **Дисциплина** | Насколько буквально исполняет приказ; склонность к нарушениям |
| **Инициативность** | Частота самостоятельных решений без запроса |
| **Осторожность** | Порог отступления, размер резерва, запросы помощи |
| **Агрессивность** | Склонность к контратакам, вылазкам, преследованию |
| **Авторитет** | Как бойцы выполняют его приказы; устойчивость морали взвода |
| **Стрессоустойчивость** | Как быстро деградирует под огнём; риск срыва |
| **Доверие к капитану** | Выполняет ли «странные» приказы без вопросов; честность докладов |
| **Отношение к подчинённым** | Бережёт людей или тратит их; влияет на мораль и на готовность отступать |
| **Самостоятельность** | Объём решений, принимаемых без звонка в штаб (растёт от доверия игрока) |
| **Способность к решениям** | Скорость реакции; склонность к «параличу» в хаосе |

Плюс **динамические состояния**: стресс, усталость, ранение, обида, уверенность, горе (после гибели близких бойцов).

### 4.3. Поведение важнее цифр

Характеристики проявляются через:
- **речь** — лексика, длина докладов, уверенность голоса, просьбы;
- **тайминг** — кто звонит сразу, а кто ждёт до последнего;
- **решения** — где ставит пулемёт, сколько держит в резерве;
- **физическое присутствие** — как ведёт себя в штабе (стоит смирно / садится без спроса / курит / трясутся руки);
- **записи в журнале взвода**, которые игрок может прочитать.

### 4.4. Ошибки и инициатива

Командир может:

| Действие | Когда возникает |
|---|---|
| Неправильно понять приказ | Плохая связь, двусмысленная формулировка, усталость, низкий опыт |
| Отказаться | Приказ = почти верная гибель взвода, низкое доверие, высокая забота о людях |
| Проявить инициативу | Высокая инициативность + самостоятельность, видит возможность |
| Попросить помощи | Осторожность, реальная угроза, или — манипуляция для получения ресурсов |
| Сменить позицию | Позиция простреливается, укрепления разрушены |
| Контратаковать | Агрессивность, противник ослаблен, шанс вернуть потерянное |
| Отступить без приказа | Мораль/стресс критичны, или — разумное решение спасти людей |
| Поддержать соседа | Хорошие отношения между командирами, общий участок |

**Отказ — не баг, а диалог.** Командир объясняет причину; игрок может настоять (−доверие, если приказ оказался плохим; +доверие к игроку, если оказался верным), уступить, или пригрозить.

### 4.5. Отношения между командирами

У каждой пары командиров есть отношение (−100…+100): дружба, соперничество, неприязнь. Это влияет на:
- готовность поддержать соседа без приказа;
- обмен боеприпасами «по-соседски»;
- корректность докладов друг о друге («Коваль опять паникует, капитан, у него там тихо»);
- реакцию на гибель другого командира.

## 6. Система приказов

### 6.1. Приказ = Намерение + Задача + Ограничения

Приказ строится не из выпадающего меню юнитов, а как **фраза**, собираемая из блоков (в духе «диалогового конструктора»):

```
[КОМУ] Третий взвод
[ЗАДАЧА] удерживать
[ГДЕ] северный сектор, рубеж «Берёзы»
[ДО КАКИХ ПОР] до 06:00 / до смены / до особого распоряжения
[УСЛОВИЯ] при угрозе окружения — отойти на вторую линию
[СВОБОДА] действовать по обстановке / строго по приказу
[ПРИОРИТЕТ] сберечь людей / удержать любой ценой
```

Игрок может отдать **короткий приказ** («Третий — держать север») — тогда командир сам заполняет пробелы **исходя из своего характера**. Коваль поймёт «любой ценой», Сомов — «держать, пока разумно».

### 6.2. Типы задач (v1.0)

| Задача | Описание |
|---|---|
| Удерживать | Оборона сектора/рубежа |
| Отойти | На указанный рубеж / к штабу |
| Контратаковать | Вернуть потерянную позицию |
| Усилить | Передать часть сил соседу |
| Сменить | Отвести на отдых, принять смену |
| Выдвинуться | Резерв → точка |
| Разведать | Послать дозор/поиск |
| Подготовить | Запасную позицию, засаду, минирование (с инженерами) |
| Экономить боеприпасы | Режим огня |
| Доложить лично | Вызвать командира в штаб |

### 6.3. Каналы передачи и искажение

| Канал | Скорость | Надёжность | Особенности |
|---|---|---|---|
| Лично в штабе | Мгновенно | 100% | Можно уточнить, увидеть реакцию; командир вне взвода 20–60 мин |
| Телефон | Быстро | Высокая, пока цел провод | Провод рвётся от обстрела; линейщики чинят |
| Рация | Быстро | Средняя | Помехи, слышит противник (риск перехвата), батареи |
| Курьер | 10–40 мин | Зависит от маршрута | Может погибнуть, приказ устареет; надёжен при полном отсутствии связи |
| Сигнальные ракеты | Мгновенно | Низкая (простые сигналы) | Заранее обговорённые коды: «отход», «нужна помощь» |

**Искажение** при плохой связи: часть приказа теряется («...держать... до... отходить...»), командир переспрашивает или действует по своему разумению. В журнале связиста фиксируется, что было отправлено и что подтверждено.

### 6.4. Подтверждение и обратная связь
Командир всегда **повторяет приказ своими словами**. Это главный инструмент проверки: если в повторе ошибка — игрок может поправить. При плохой связи повтор может не дойти.

## 7. Система доверия и отношений

### 7.1. Двусторонняя модель
- **Доверие командира к капитану** (видимо через поведение).
- **Доверие капитана к командиру** — неявно, через действия игрока (система считает частоту вмешательств, проверок, перепроверок).

### 7.2. Память командира

Каждый командир хранит **журнал эпизодов** (ограниченный, 20–40 значимых событий) с эмоциональной окраской:

```
[День 2, 14:20] Капитан не дал резерв, когда я просил. Потеряли окоп. (−, сильное)
[День 2, 22:00] Капитан лично пришёл в блиндаж, вручил благодарность. (+, сильное)
[День 3, 05:10] Капитан отменил мою контратаку за 5 минут до начала. (−, среднее)
```

Эпизоды затухают со временем, но «сильные» не забываются. Из них формируются **убеждения**:
- «Капитан меня слышит» / «Капитан не слушает»;
- «Капитан бережёт людей» / «Капитан кидает нас в мясорубку»;
- «Капитан даёт свободу» / «Капитан всё контролирует».

### 7.3. Влияние решений игрока

| Действие игрока | Эффект |
|---|---|
| Даёт свободу, и командир справляется | +самостоятельность, +доверие, +уверенность |
| Даёт свободу, командир проваливается, игрок не наказывает | +лояльность, −уверенность (учится) |
| Часто перепроверяет, отменяет решения | −инициатива, командир начинает звонить по каждому поводу («выученная беспомощность») |
| Справедливое наказание за реальную ошибку | +дисциплина, нейтрально к доверию |
| Несправедливое наказание (командир был прав или ситуация была невыполнимой) | −−доверие, обида, риск скрытых докладов, слухи по гарнизону |
| Помогает в кризисе | +доверие, +честность докладов |
| Игнорирует просьбы | −доверие; у осторожных — рост паники, у агрессивных — самоуправство |
| Посещает позиции | +авторитет капитана у бойцов, +мораль |
| Публично хвалит | +мораль взвода, ревность у соперников |

### 7.4. Репутация капитана в гарнизоне
Скрытая общая метрика, распространяемая через **слухи**: командиры обсуждают решения капитана между собой. Несправедливость к одному — снижает доверие у его друзей.

### 7.5. Дисциплинарные инструменты
Замечание, выговор (в журнал), отстранение, арест, разжалование, представление к награде, благодарность перед строем, личный разговор. Каждый — с последствиями, видимыми через поведение.

## 8. Штаб

### 8.1. Пространство

Главный блиндаж — 3 помещения + выход в траншею:

```
 ┌─────────────────────┬─────────────┐
 │  КОМНАТА КОМАНДИРА  │   УЗЕЛ      │
 │  стол с картой      │   СВЯЗИ     │
 │  лампа, койка       │   рация     │
 │  сейф с документами │   коммутатор│
 │                     │   связистка │
 ├─────────────────────┴──────┬──────┘
 │  ПРЕДБАННИК / ЖДУЩИЕ        │
 │  скамья (приходящие         │
 │  командиры), вешалка,       │
 │  ящики, позже — раненые     │
 └──────────┬──────────────────┘
            │ ход сообщения → траншея → НП / медпункт / склад
```

### 8.2. Диегетический интерфейс

| Объект | Функция |
|---|---|
| **Стол с картой** | Главная карта. Игрок сам ставит фишки и пометки карандашом. На полях — время пометки. Камера переходит в вид сверху, но лампа, тени и кружка чая остаются |
| **Карта секторов на стене** | Схема ответственности взводов, рубежей, запасных позиций |
| **Телефон-коммутатор** | Входящие звонки (звонок + лампочка нужного абонента), исходящие — выбор штекера |
| **Рация** | Связь с вышестоящими, разведкой, дальними постами; ручка настройки, помехи |
| **Журнал боевых действий** | Автоматически ведётся адъютантом/связистом: все доклады с временем получения |
| **Папка донесений** | Письменные доклады, сводки, записки курьеров (почерк, пятна, неразборчивость) |
| **Ведомость снабжения** | Таблица, заполненная от руки старшиной: что на складе, что ожидается |
| **Личные дела командиров** | Краткая характеристика + заметки капитана (игрок может делать свои) |
| **Часы на стене** | Единственный точный источник времени |
| **Амбразура / перископ** | Ограниченный вид на ближайший сектор |
| **Сейф** | Приказы сверху, коды сигналов, секретные пакеты (события) |
| **Ящик с ракетницей** | Сигналы «общая тревога», «отход» |

**HUD:** только минимальная точка-прицел и контекстная подсказка взаимодействия. Никаких полос здоровья, мини-карт, счётчиков ресурсов. В настройках — «режим доступности»: компактный блокнот-оверлей с последними 5 докладами.

### 8.3. Люди в штабе
- **Связистка Мирон** — передаёт звонки, держит очередь абонентов, может напомнить о неотвеченных.
- **Адъютант (ординарец)** — приносит чай, сводки, напоминает о времени, сообщает, кто ждёт в предбаннике.
- **Приходящие командиры** — ждут на скамье. Чем дольше ждут, тем больше раздражаются (или уходят обратно, оставив записку).
- **Комендантское отделение** — 6–8 бойцов охраны штаба, последний резерв.

### 8.4. Личные доклады

Командир приходит, если:
- нужна санкция на серьёзное решение (отход, контратака);
- связь нарушена;
- он хочет говорить «не по телефону» (конфликт, жалоба, просьба);
- его вызвали.

Диалог: командир говорит, игрок выбирает реплики-тезисы (не меню действий, а *позиции*): «Сколько у вас осталось патронов?», «Почему не доложили раньше?», «Делайте, как считаете нужным», «Нет. Держать». Важна **интонация** ответа (твёрдо / мягко / раздражённо) — влияет на отношения.

Пока командир в штабе — его взвод управляется заместителем (обычно хуже).

### 8.5. Штаб как критическая точка — «Шкала обречённости»

Захват штаба = поражение, но это **процесс из 6 стадий**, каждая с ощутимыми физическими признаками:

| Стадия | Обстановка | Что ощущает игрок |
|---|---|---|
| 0. Тыл | Бой далеко | Отдалённая канонада, связь в норме |
| 1. Давление | Потеряна часть внешних позиций | Чаще рвётся провод, тревожные доклады |
| 2. Прорыв | Противник во второй линии | С потолка сыплется земля, лампа качается, связь пропадает пачками, курьеры не возвращаются |
| 3. Близкий бой | Бой в 200–300 м от штаба | Слышна стрелковая стрельба, раненых несут прямо в предбанник, связистка просит разрешения сжечь документы |
| 4. Осада штаба | Бой у хода сообщения | Комендантское отделение ведёт огонь, гранаты у входа, командиры звонят с предупреждениями, игрок может сам взять оружие |
| 5. Падение | Противник в штабе | Поражение (если не удалась эвакуация штаба на запасной КП) |

**Запасной КП** — игрок может заранее подготовить с помощью инженеров. Переезд штаба = 1–2 часа без связи, но шанс продолжить.

## 9. Подразделения

### 9.1. Состав гарнизона (v1.0)

| Подразделение | Численность | Вооружение |
|---|---|---|
| 1–4 стрелковые взводы | 25–32 чел. каждый | Винтовки, 2 ручных пулемёта, 1 станковый пулемёт |
| Инженерный взвод | 18 чел. | Инструмент, мины, взрывчатка |
| Миномётная секция | 2 миномёта, 10 чел. | Ограниченные мины |
| Разведотделение | 8 чел. | — |
| Связисты | 6 чел. | Телефон, рация, катушки провода |
| Медпункт | 1 врач, 1 фельдшер, 4 санитара | — |
| Хозвзвод (тыл) | 10 чел. | Склад, кухня, подвоз |
| Комендантское отделение | 8 чел. | Охрана штаба |

Итого ≈ 180–200 человек. Каждый боец **существует как запись** (имя, ранг, состояние, навык), но игрок видит их только в списках, блиндажах и в репликах.

### 9.2. Состояние подразделения

| Параметр | Описание | Как игрок узнаёт |
|---|---|---|
| Мораль | Готовность сражаться | Тон доклада, слухи, визит |
| Усталость | Физическое истощение | Просьбы о смене, ошибки |
| Боеспособность | Итоговая эффективность | Результаты боя |
| Боеприпасы | Патроны, гранаты, ленты | Запросы, ведомости |
| Раненые | Легко / тяжело / нетранспортабельные | Медпункт, доклады |
| Укрепления | Целостность окопов, ДЗОТов, блиндажа | Инженеры, визит |
| Связь | Качество канала | Задержки, помехи |
| Эффективность командования | Состояние командира + заместителей | Косвенно |

Эти значения **не показываются числами**. Игрок получает их через формулировки: «боеприпасов на два хороших боя», «люди держатся, но третью ночь не спят».

### 9.3. Внутренняя симуляция взвода
Взвод делится на 3 отделения + пулемётные расчёты + резерв взвода. Командир взвода распределяет их по позициям сектора (каждый сектор — 4–8 огневых точек). Бой симулируется абстрактно-позиционно (огневые точки, линии огня, подавление, потери), а визуализируется только там, где игрок может это видеть.

## 10. Блиндажи

Каждый взвод имеет свой блиндаж — живое 3D-пространство, которое игрок может посетить.

**Что там видно:**
- спящие/курящие/чистящие оружие бойцы — их поведение отражает мораль и усталость;
- ящики с боеприпасами (их **реально видно** — пустые или полные);
- раненые на нарах, ждущие эвакуации;
- телефонист, лампа, печка;
- командир, работающий над своей картой (его карта отражает **его** модель обстановки — можно увидеть, как он понимает ситуацию!);
- следы обстрелов, сырость, вода на полу.

**Зачем посещать:**
- узнать правду (сравнить доклад с реальностью);
- поднять мораль;
- поговорить с бойцами (слухи, жалобы, неочевидная информация);
- лично отдать сложный приказ;
- увидеть сектор своими глазами из окопа.

**Цена:** время, риск под обстрелом, штаб без капитана (начальник штаба/адъютант принимает звонки, но решения откладываются).

Состояние блиндажа: целый → повреждён → разрушен (взвод теряет укрытие, растёт усталость и потери от обстрелов).

## 11. Медпункт

### 11.1. Устройство
Отдельный блиндаж рядом со штабом (или в глубине обороны): операционный стол, сортировочная зона, нары, «чёрный угол» (безнадёжные), запас медикаментов.

### 11.2. Ресурсы
- **Персонал:** врач (операции), фельдшер (сложные перевязки), санитары (переноска, перевязки). Каждый устаёт и может погибнуть.
- **Медикаменты:** перевязочные материалы, обезболивающее, антисептики, кровезаменители, инструмент.
- **Места:** ограниченное число нар.

### 11.3. Механика
- Раненые поступают из взводов (санитары взводов выносят — если могут).
- **Сортировка:** врач сортирует сам, но игрок может задать приоритеты: «Сначала тех, кто может вернуться в строй» / «Сначала тяжёлых» / «Командиров в первую очередь».
- Легкораненые возвращаются в строй через 6–24 ч.
- Тяжёлые требуют эвакуации — **которой нет**, пока кольцо не прорвано. Они занимают место и медикаменты.
- Нехватка → смертность растёт → мораль гарнизона падает («в медпункт идти — умирать»).

### 11.4. Дилеммы
- Отдать спирт врачу или оставить для обмена/обогрева?
- Отправить санитаров на передовую выносить раненых (риск) или держать в медпункте?
- Решение по нетранспортабельным при отходе.
- Попытка вывезти тяжёлых через кольцо ночью (риск потерять группу).

## 12. Снабжение

### 12.1. Ресурсы

| Ресурс | Расход | Последствия нехватки |
|---|---|---|
| Патроны / пулемётные ленты | Бой | Падение огневой мощи, отход |
| Гранаты | Ближний бой | Хуже отражение штурма |
| Мины для миномётов | Огневая поддержка | Нет поддержки |
| Медикаменты | Раненые | Рост смертности |
| Еда | Постоянно | Усталость, мораль |
| Вода | Постоянно | Быстрее всего критична! |
| Инженерные материалы (лес, проволока, мешки, мины) | Строительство | Нет укреплений |
| Батареи / провод | Связь | Обрывы без ремонта |
| Топливо / керосин | Свет, тепло | Ночью — холод, мрак, мораль |
| Табак | Мораль | Мелкий, но заметный |

### 12.2. Источники
1. **Склад гарнизона** — стартовый запас (старшина Дьяков, у которого есть «заначка» — можно найти при доверии/давлении).
2. **Сброс с воздуха** (ночью, по запросу — 40–70% груза в зоне гарнизона, часть уходит к противнику, часть в ничейную полосу → требуется вылазка).
3. **Прорыв колонны** (редкое событие).
4. **Трофеи** (после удачной контратаки — немного).
5. **Внутреннее перераспределение** — между взводами.

### 12.3. Логистика внутри обороны
Склад → подносчики (хозвзвод) → взводы. Подносчики идут по ходам сообщения и могут попасть под обстрел. Игрок решает **распределение** и **время доставки** (днём — быстрее и опаснее, ночью — медленнее и безопаснее).

### 12.4. Нестабильность поставок
Каждая поставка имеет: обещанное время, реальное время, обещанный состав, реальный состав. Игрок узнаёт о реальном составе только после пересчёта старшиной («Капитан, обещали 40 ящиков патронов, пришло 22 и 6 ящиков валенок»).

## 13. Резерв

### 13.1. Что такое резерв
- **Гарнизонный резерв** — обычно один взвод на отдыхе (ротация) + комендантское отделение + часть инженеров.
- **Резерв взвода** — отделение, которое командир взвода держит сам.

### 13.2. Размещение (v1.0 — 3 точки)

| Позиция | Время реакции на север / юг / восток / запад | Плюсы / минусы |
|---|---|---|
| У штаба | 25 / 25 / 25 / 25 мин | Защищает штаб, медленно ко всем |
| Центр обороны | 15 / 15 / 15 / 15 мин | Универсально, хуже отдых |
| У опасного направления | 5 / 30 / 20 / 20 мин | Быстро на одно направление, плохо на другие, под обстрелом |

### 13.3. Механики
- Резерв **отдыхает** только если не дёргается (каждое выдвижение без боя — усталость).
- Выдвижение резерва раскрывается противнику (его разведка видит перемещения днём).
- Использованный резерв **нельзя вернуть мгновенно** — нужно время на выход из боя.
- Противник специально проводит **ложные атаки**, чтобы выманить резерв.

Ключевой вопрос, который игра постоянно задаёт: *«Это главный удар — или отвлекающий?»*

## 14. Смены и усталость

### 14.1. Усталость
Накапливается от: нахождения на передовой, боя, обстрелов, ночного бодрствования, холода, голода.
Восстанавливается: сон в целом блиндаже, еда, тепло, тишина.

### 14.2. Влияние усталости

| Уровень | Эффект |
|---|---|
| Свежие | Норма |
| Утомлены | −реакция, медленнее исполнение приказов |
| Измотаны | −точность, −дисциплина, ошибки часовых, задержка докладов |
| На пределе | −мораль, −инициатива командира, риск засыпания на посту, неверные доклады |
| Сломлены | Самовольный отход, паника, отказ от приказов |

Усталость действует и на **командира** — уставший Ярцев становится ещё более рискованным, уставший Сомов — ещё более паникёрским.

### 14.3. Смены
- Командир сам запрашивает смену («Капитан, мои третьи сутки не спят»). Осторожные — рано, исполнительные — поздно (или никогда).
- Смена занимает 1–2 часа: выход одного взвода, вход другого; **в момент смены сектор уязвим**.
- Лучшее время — ночь или после отражения атаки.
- Противник может **засечь** смену и ударить в этот момент.

### 14.4. Решение игрока
Заменить / прислать часть резерва / оставить / пообещать смену позже (обещания запоминаются! невыполненное обещание — сильный минус доверия).

## 15. Разведка

### 15.1. Источники

| Источник | Что даёт | Надёжность |
|---|---|---|
| **Наблюдательные посты (НП)** — 2–4 шт. | Движение в секторе обзора, артобстрелы, дым | Средняя; ночью/в туман низкая |
| **Разведгруппы** (ночные поиски) | Позиции, численность, подготовка атаки | Высокая, но редко; могут погибнуть |
| **Пленные** | Планы, номера частей | Может лгать |
| **Командиры взводов** | Что видят на своём участке | Окрашено личностью |
| **Радиоперехват** (редко) | Фрагменты переговоров | Обрывочно |
| **Сверху (командование)** | Общая картина | Часто устаревшая |

### 15.2. Качество разведданных
Каждое донесение имеет скрытую **точность** и **время наблюдения**. Игрок видит лишь:
- кто сообщил;
- когда (время наблюдения vs время получения);
- формулировку («до роты пехоты», «шум моторов»).

Ошибки: завышение/занижение численности, неверное направление, принятие ложной подготовки за настоящую, дезинформация противника.

### 15.3. Решения игрока
Куда отправить разведку, сколько людей рисковать, перепроверить ли данные вторым источником (стоит времени).

## 16. Связь

### 16.1. Сеть
Телефонная сеть — граф: штаб ↔ взводы ↔ НП ↔ медпункт ↔ склад. Провода проходят по реальным маршрутам на карте и рвутся там, где падают снаряды.

### 16.2. Состояния линии
Норма → помехи → прерывистая → оборвана. Связисты-линейщики выходят на ремонт (риск, время).

### 16.3. Рация
- Батареи ограничены.
- Противник может **пеленговать** долгие сеансы → обстрел штаба.
- Противник может **подслушивать** открытым текстом → необходимость кодов (таблица позывных в сейфе).

### 16.4. Последствия потери связи
Командир взвода переходит в **автономный режим** — действует по последнему приказу + своему характеру. Это момент истины: доверие, выстроенное ранее, окупается — или нет.

## 17. Инженеры

### 17.1. Задачи

| Задача | Время | Материалы |
|---|---|---|
| Укрепить позицию (углубить окопы, накатник) | 3–6 ч | Лес, мешки |
| Отремонтировать блиндаж | 2–5 ч | Лес |
| Построить огневую точку / ДЗОТ | 6–10 ч | Лес, мешки |
| Запасная позиция / отсечная траншея | 4–8 ч | — |
| Минирование направления | 2–4 ч | Мины |
| Проволочные заграждения | 2–4 ч | Проволока |
| Расчистка завалов / ходов | 1–3 ч | — |
| Запасной КП | 8–12 ч | Лес |
| Восстановление после обстрела | Переменно | Переменно |

### 17.2. Ограничения
Инженеров 18. Их можно разделить на 2–3 группы. Работы днём — под огнём (медленнее, потери), ночью — быстрее, но шум может выдать позиции.

### 17.3. Решение
Лучко даёт **честную оценку сроков**; игрок решает, где нужнее. Инженеры могут быть брошены в бой как пехота (последний резерв), но это — потеря незаменимых специалистов.

## 18. Мораль

### 18.1. Уровни
- **Мораль бойцов взвода**;
- **Мораль командира**;
- **Общая мораль гарнизона** (среднее + слухи).

### 18.2. Факторы

| Плюс | Минус |
|---|---|
| Успешное отражение атаки | Потери, особенно друзей |
| Еда, тепло, сон | Голод, холод, жажда |
| Визит капитана | Ощущение заброшенности |
| Новости о деблокаде | Сорванные сроки деблокады |
| Награды, благодарность | Несправедливость |
| Почта / сброс с письмами | Раненые без помощи |
| Сильный командир | Паника соседей |
| Работающий медпункт | Слухи о смерти в медпункте |

### 18.3. Проявление
Не полоска, а поведение: песни/тишина в блиндаже, шутки по телефону, дезертирство, самострелы (редкие тёмные события), бойцы, приходящие к штабу с просьбами.

### 18.4. Слухи
Система распространения слухов между взводами: «говорят, деблокада отменена», «говорят, третий взвод бросил позиции». Игрок может опровергать слухи (визит, обращение по телефону), но ложь, позже вскрывшаяся, сильно бьёт по доверию.

## 19. Туман информации

Это не отдельная механика, а **принцип, пронизывающий всё**.

### 19.1. Карта игрока ≠ реальность
- Карта на столе обновляется **только руками игрока** (или адъютант по приказу «нанести последние доклады» — с ошибками).
- На каждой пометке — время. Игрок видит, насколько информация стара.

### 19.2. Источники неопределённости
1. **Задержка** — доклад о событии 30 мин назад.
2. **Неполнота** — «видим движение» без численности.
3. **Субъективность** — каждый командир окрашивает доклад характером.
4. **Искажение связи** — потеря фрагментов.
5. **Дезинформация** противника — ложные огни, шумы моторов, ложные радиопереговоры.
6. **Молчание** — отсутствие доклада не означает спокойствия.

### 19.3. Инструменты против тумана
Перекрёстная проверка, личный визит, вызов командира, разведка, знание характеров («Сомов всегда умножает на два»).

### 19.4. Реальность раскрывается после
После завершения боя/дня — **«разбор»** (опционально): что было на самом деле. Это обучает игрока читать людей.

## 20. Поведение противника

### 20.1. Иерархия ИИ противника

```
КОМАНДИР ОПЕРАЦИИ (стратегия на сутки)
   ├─ Цель: взять Цитадель к дню X / измотать / найти слабое место
   ├─ Ресурсы: батальоны, артиллерия, боеприпасы, резервы
   ├─ Разведка: собственная модель обороны игрока (тоже неполная!)
   │
   ├── КОМАНДИРЫ БАТАЛЬОНОВ (тактика по направлениям)
   │     └─ Роты → взводы (атаки, подавление, просачивание)
   │
   ├── АРТИЛЛЕРИЯ (планы огня, контрбатарейка по миномётам, огонь по разведанным целям)
   └── СНАБЖЕНИЕ ПРОТИВНИКА (ограничивает интенсивность)
```

### 20.2. Принципы
- **Нет бесконечных волн.** У противника есть конечный «бюджет» сил на операцию; он подтягивает подкрепления по расписанию, которое игрок может узнать через разведку.
- **Противник учится:** запоминает, где были сильные огневые точки, куда выдвигается резерв, когда происходят смены.
- **Противник обманывает:** ложные атаки, демонстрации, ночные шумы, отвлекающий артобстрел.

### 20.3. Тактические сценарии (планы)

| План | Описание |
|---|---|
| **Изматывание** | Беспокоящий огонь, ночные вылазки, срыв сна |
| **Отвлечение** | 2–3 атаки на направление А → удар по Б |
| **Просачивание** | Ночью малые группы через стыки взводов |
| **Штурм** | Массированная артподготовка + атака на узком участке |
| **Охота на связь** | Огонь по проводам, пеленгация рации |
| **Удушение** | Перехват сбросов снабжения, обстрел склада и воды |
| **Обезглавливание** | Поиск и удар по штабу (если разведал его место) |

### 20.4. Модель обороны у противника
Противник видит гарнизон тоже через разведку: если игрок держит пулемёт скрытно — противник о нём не знает. Это позволяет устраивать **засады** и **ложные позиции**.

### 20.5. Личности командиров противника
Командир операции имеет архетип (методичный / азартный / осторожный / жестокий). Игрок может распознать стиль по поведению и подстроиться. В 2-й половине кампании командир может смениться.

## 21. Система событий

### 21.1. Типы
- **Системные** — порождаются симуляцией (атака, обрыв связи, нехватка воды).
- **Сюжетные** — заданные кампанией (приказ сверху, сроки деблокады, сброс).
- **Личные** — из жизни командиров и бойцов (письмо из дома, конфликт, срыв, подвиг).
- **Моральные дилеммы** — выбор без правильного ответа.

### 21.2. Режиссёр (Event Director)
Отслеживает «напряжение» сессии и регулирует частоту не-боевых событий, чтобы:
- после тяжёлого боя давать паузу с «человеческими» событиями;
- в долгих тихих периодах подбрасывать тревожные сигналы (не всегда реальные);
- не допускать бессмысленного нагромождения.

Режиссёр **не управляет противником напрямую** — только событиями окружения и сюжетом.

### 21.3. Примеры событий

| Событие | Выбор |
|---|---|
| Пленный утверждает, что атака будет на юге в 4 утра | Поверить / перепроверить / игнорировать |
| Ярцев просит разрешения на ночную вылазку за трофейным пулемётом | Разрешить / отказать / разрешить с ограничениями |
| Сброс упал в ничейную полосу | Вылазка за ним (риск) / оставить |
| Боец сбежал, его поймали | Трибунал / простить / отправить в штрафную группу (последствия для морали) |
| Сомов в истерике после гибели заместителя | Утешить / отстранить / оставить |
| Врач требует остановить бой на час для эвакуации раненых с передовой | Невозможно / частично |
| Сверху: «держаться ещё 2 суток» (вместо обещанных 12 часов) | Как сообщить гарнизону? Правда / ложь / молчание |
| Противник предлагает сдаться через громкоговоритель | Реакция гарнизона зависит от морали |
| Колодец отравлен / разрушен | Поиск воды |

## 22. День и ночь

### 22.1. Цикл
Полный цикл суток, освещение — ключевой элемент PS1-атмосферы: днём — серый туман, ночью — чёрный туман с пятнами ламп и вспышками ракет.

### 22.2. День
- Противник: артобстрел, атаки, авиация (событийно), наблюдение.
- Гарнизон: оборона, ограниченное перемещение, медленное снабжение внутри обороны.
- Хорошая видимость → точная разведка с НП.

### 22.3. Ночь
- Противник: просачивание, разведка, беспокоящий огонь, ночные штурмы.
- Гарнизон: смены, подвоз, ремонт, инженерные работы, разведпоиски, сбросы снабжения, эвакуация раненых.
- Плохая видимость → туман информации сильнее, ракеты на миг освещают поле.
- Усталость накапливается, если ночь беспокойная.

### 22.4. Рассвет и сумерки
Самые опасные периоды — классическое время атак. Игрок учится к ним готовиться («утренняя готовность»).

### 22.5. Погода (простая в v1.0)
Ясно / туман / дождь / снег. Влияет на видимость, связь, мораль, усталость, звук.

### 22.6. Сон капитана
Капитан тоже устаёт. Можно лечь поспать на 2–4 часа (время ускоряется, решения принимает начальник штаба — по своей логике). Без сна: экран начинает «плыть» (PS1-эффекты усиливаются: дрожание, искажения цвета, пропуск реплик), ухудшается чтение документов. Это диегетическое выражение усталости игрока.

## 23. Условия победы и поражения

### 23.1. Победа
- **Основная:** удержать оборону до деблокады (дата может сдвигаться событиями!).
- **Альтернативная:** прорыв из окружения по приказу — организовать выход с сохранением максимального числа людей.
- **Частичная:** удержаться, но с огромными потерями.

### 23.2. Поражение
- Захват штаба (через описанные 6 стадий).
- Полная потеря боеспособности гарнизона (все взводы сломлены).
- Капитан убит (при личном выходе на передовую или в бою у штаба).
- Капитан снят с должности командованием (за неподчинение / провал задач) — редкий исход.
- Капитуляция (выбор игрока или бунт гарнизона при очень низкой морали и доверии).

### 23.3. Оценка
Итоговый **рапорт** (машинописный, с подписью) вместо экрана очков:
- сохранённые люди;
- потери по взводам;
- судьбы командиров (кто погиб, кто вырос, кто сломался);
- выполнение задач;
- отношения с подчинёнными;
- медали, представления;
- «что было на самом деле» — карта реальных действий противника.

## 24. Как игрок должен быть занят в течение игрового дня

Типичный игровой день (≈ 1,5–2 реальных часа):

| Время | Фаза | Занятия игрока |
|---|---|---|
| 04:00–06:00 | Утренняя готовность | Проверить готовность взводов, выдвинуть резерв, принять доклады НП, ожидание атаки |
| 06:00–09:00 | Утренний бой | Доклады, решения о резерве, распределение мин миномётам, раненые |
| 09:00–12:00 | Разбор | Учёт потерь, распределение боеприпасов, приказ инженерам, разговоры с командирами |
| 12:00–15:00 | Дневное давление | Обстрелы, обрыв связи, ремонт линий, малые атаки, разведданные |
| 15:00–18:00 | Подготовка к ночи | Планирование смен, подвоз, ночные задачи инженерам, разведпоиски |
| 18:00–20:00 | «Вечерний совет» | Командиры в штабе: общий разговор, споры, план на ночь |
| 20:00–04:00 | Ночь | Смены, сброс снабжения, просачивание противника, вылазки, личные события, сон капитана |

**Правило ритма:** не более 5–7 минут реального времени без значимого входящего сигнала, но не каждый сигнал — тревога. Тихие периоды заполнены «бумажной» работой, разговорами и подготовкой.

## 25. Как сделать игру интересной без постоянного экшена

1. **Напряжение ожидания.** Тишина — тоже информация. Телефон, который *не* звонит, — пугает.
2. **Звук как главный канал.** Далёкий бой, приближение разрывов, звонок, помехи, шаги в ходе сообщения — до того, как увидишь, кто вошёл.
3. **Люди с историей.** Командиры, которых узнаёшь, к которым привязываешься и которых теряешь.
4. **Решения с ценой.** Почти каждое решение — выбор между двумя плохими вариантами.
5. **Загадка обстановки.** Игра в детектива: сопоставь доклады, найди ложь, угадай план противника.
6. **Последствия с задержкой.** Решение, принятое утром, «выстреливает» ночью.
7. **Ритуалы.** Вечерний совет, утренний чай от ординарца, подпись донесений — создают ощущение жизни.
8. **Физическое пространство.** Предметы меняются: чашки накапливаются, карты покрываются пометками, лампа коптит, потолок осыпается.
9. **Редкий, но сильный экшен.** Когда бой приходит к штабу — это шок именно потому, что до этого игрок воевал через телефон.
10. **Неопределённость исхода.** Игрок никогда не уверен, что победит, до последнего часа.

## 26. Как реализовать ощущение настоящего командования

- **Дистанция:** игрок не видит бой — он видит последствия и слышит людей.
- **Посредники:** каждое действие проходит через человека, который может ошибиться.
- **Формулировка приказов:** важно *что* и *как* сказано, а не какую кнопку нажал.
- **Время:** приказ идёт, исполняется и даёт эффект не мгновенно.
- **Ответственность:** имена погибших в журнале; вопросы врача; глаза командира, который вернулся из боя без половины взвода.
- **Доверие как ресурс:** самый ценный ресурс игры — не патроны, а люди, которым можно доверить участок.
- **Документы:** подпись приказа — отдельное действие с ручкой; бумажные донесения с почерком.
- **Иерархия сверху:** у капитана тоже есть начальник, который требует, обещает и не выполняет.
- **Ни одного «бога»-инструмента:** нет просмотра всей карты, нет паузы, нет числовых панелей.
- **Голос:** разные голоса командиров (даже при PS1-стиле — озвучка или «бормотание» в стиле ретро-игр + субтитры).

## Приложение A. Техническое направление (предварительно, для этапа прототипа)

- **Движок:** Godot 4 (лёгкий, отличная поддержка шейдеров для PS1-стиля, экспорт в Android APK и PC) — либо Unity URP.
- **ИИ командиров:** HTN-планировщик + Utility AI + система памяти (ECS-friendly).
- **Симуляция боя:** абстрактная, тиковая (1 тик = 10 сек игрового времени), визуализация только наблюдаемых участков.
- **Диалоги:** Ink / Yarn Spinner с параметрической подстановкой состояния командиров.
- **Данные:** все характеры, события и приказы — в JSON/Resource-файлах для удобного баланса.

## Приложение B. Ближайшие шаги

1. Вертикальный срез: штаб + 2 взвода + телефон + 1 атака противника + 2 командира (Коваль и Ярцев).
2. Проверка гипотезы: «интересно ли командовать, не видя боя».
3. Сборка тестового APK (Android) и PC-билда вертикального среза.
4. Плейтесты, затем — расширение до полного состава 1.0.
